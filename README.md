# ai-for-codex

An interactive React-based advanced file uploader demo that simulates multi-file uploads with real-time progress tracking, localization (简体中文 / English), and a paginated results table.

## Getting started

This project runs entirely in the browser without a build step. Serve the repository root with any static file server, for example Python's built-in HTTP server:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173/` in your browser to use the uploader interface.
